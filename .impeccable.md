## Design Context

Source of truth: `DESIGN-figma.md` (visual system). This file adapts it to a
Windows desktop tool built in Tkinter.

### Users
One person documenting how they do a task on their own PC: they record clicks,
typing and spoken narration, then tidy the result into a step-by-step guide
(often used as training context for an AI). Two very different moments:
- **Capturing**: the control window floats on top while they work in *other*
  apps. It must be glanceable, quiet, and unmistakable about state
  (idle / recording / paused / transcribing).
- **Reviewing**: a focused editing session — rename, reorder, redact
  screenshots, fix transcript typos, export.

### Brand Personality
Technical and joyful. "Editorial, calm, decisive." A serious tool made by
people who like color. Confidence comes from type and contrast, not chrome.

### Aesthetic Direction
- Monochrome frame: white canvas `#ffffff`, black ink `#000000`, hairline
  `#e6e6e6`, surface-soft `#f7f7f5`. No mid-gray body text; weight carries
  hierarchy. Pure black/white is intentional here (spec overrides the usual
  "tint your neutrals" rule).
- **One pastel color block per window**, used as the state surface:
  lime = idle/ready, coral = recording, cream = paused, lilac = transcribing.
- Pills for every text button; circles for every icon button. Black pill =
  the single primary action per view. Selected = black surface.
- Type: Segoe UI at Light / Semilight / Regular / Semibold stands in for
  figmaSans' variable weights (340 / 330 / 480 / 540). Cascadia Mono, uppercase,
  tracked, stands in for figmaMono — eyebrows and captions only.
- Icons: Segoe MDL2 Assets (one consistent stroke family). No emoji as icons.
- Accent magenta `#ff3d8b` is single-shot: the click marker on screenshots and
  the recording tray dot.
- No shadows, no gradients, no side-stripe borders. Light theme only (spec
  documents no dark theme).

### Design Principles
1. State is a surface: the color block tells you what the recorder is doing
   before you read a word.
2. One primary per view. Everything else is secondary, ghost, or an icon circle.
3. Weight, not gray: hierarchy through Light vs Semibold, never faded text.
4. Mono is taxonomy: STEP 03, NARRATION 0:42, CLICK — labels, never prose.
5. No lazy modals: add steps inline, confirm inline with toasts; native
   dialogs only for irreversible deletes and unsaved-changes prompts.
